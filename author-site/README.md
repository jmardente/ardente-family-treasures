# Jamie Ardente — Author Homepage

An elegant author homepage for **Jamie Ardente** (fiction, romance, and creative services) and **JM Ardente** (children's books).

## Preview & status
- The site source is in `author-site/` on the `jamie-ardente-author-homepage` development branch.
- No changes were made to the existing Ardente Family Treasures live website on `main`.
- This is source code, **not a live site**. To launch independently, publish the `author-site` folder as a new Netlify site, ideally from its own GitHub repository.
- The contact form uses Netlify Forms and will not accept submissions until Netlify deployment and forms processing are configured.

## Files
- `index.html` — responsive homepage (styles included)
- `assets/author-portrait.svg` — portrait for the author hero section (pending if not yet uploaded)
- `success.html` — contact form success page

## Design
Lavender, cream and muted gold; clean editorial typography. Books showcased using book cover assets hosted publicly in the original Ardente Family Treasures repository.

## Before launch
1. Confirm book cover images, descriptions and shop links.
2. Review author bio and services, and add a verified Fiverr/profile link.
3. Confirm contact form delivery in Netlify and privacy policy.
4. Set a custom domain if desired.
